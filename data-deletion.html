Demander la suppression de vos données

Cette page explique comment effacer les données de Mama Link sur votre téléphone et comment contacter l’éditeur au sujet d’éventuelles données qu’il détiendrait.

Application : Mama LinkResponsable : Barack NdengaMise à jour : 20 novembre 2026
Mama Link ne crée pas de compte et ne conserve pas vos données de santé, profil ou conversations sur un serveur de l’éditeur. Ces informations sont stockées dans l’application sur votre appareil. Il n’existe donc pas de compte Mama Link à fermer ni de copie serveur de ces contenus à supprimer par e-mail.

1. Supprimer toutes les données locales de Mama Link

Pour effacer de manière définitive les données de l’application enregistrées sur votre téléphone :

  1. Ouvrez les Paramètres Android.
  2. Choisissez Applications, puis Mama Link.
  3. Ouvrez Stockage ou Stockage et cache.
  4. Appuyez sur Effacer les données ou Effacer le stockage, puis confirmez. Les noms exacts peuvent varier selon le téléphone.

Vous pouvez également désinstaller Mama Link ; la désinstallation supprime les données privées de l’application. La sauvegarde Android est désactivée par Mama Link. La suppression des données est irréversible : les informations supprimées ne peuvent pas être restaurées par l’éditeur.

2. Quelles données sont supprimées ?

L’effacement du stockage ou la désinstallation supprime les données enregistrées localement par Mama Link, notamment le profil et les préférences, les informations de santé et de suivi, les rendez-vous, les parcours de soins, les conversations (y compris le texte issu de la reconnaissance vocale) et les propositions d’établissements enregistrées sur ce téléphone. Cela supprime également les fichiers locaux et réglages propres à l’application.

La suppression est effectuée sur l’appareil ; Mama Link ne reçoit pas de confirmation et ne peut pas effacer à distance les données de votre téléphone.

3. Données qui peuvent rester chez des tiers

Google AdMob et UMP peuvent traiter l’adresse IP (qui peut servir à estimer une localisation générale), les interactions avec l’application, les données de diagnostic et les identifiants d’appareil ou de compte. Effacer Mama Link ne supprime pas automatiquement les données que Google a déjà traitées. Gérez les données et préférences depuis les paramètres de confidentialité du compte Google et les paramètres Android relatifs à la publicité. La conservation éventuelle relève de Google et de ses règles, que Mama Link ne contrôle pas.

Si vous utilisez la saisie vocale, l’audio peut être transmis au fournisseur de reconnaissance vocale choisi par Android. Mama Link ne conserve pas cet audio. Le texte reconnu, s’il est ajouté à une conversation, est effacé avec les données locales de Mama Link. Pour toute donnée éventuellement conservée par le fournisseur vocal, consultez ses outils et ses règles de suppression ; l’éditeur Mama Link ne peut pas l’effacer à sa place. Les périodes de conservation éventuelles sont déterminées par ces fournisseurs, pas par Mama Link.

4. Demander l’effacement de données détenues par l’éditeur

Si vous pensez avoir transmis directement à Barack Ndenga des données personnelles concernant Mama Link (par exemple dans une demande d’assistance), envoyez un e-mail à l’adresse ci-dessous. Indiquez « Demande de suppression — Mama Link » dans l’objet et décrivez le type de données concerné. N’envoyez pas de dossier médical ni d’autres détails de santé dans votre demande.

L’éditeur vérifiera si des données concernées sont effectivement détenues et traitera la demande conformément à la loi applicable. Il vous informera si certaines données ne peuvent pas être supprimées immédiatement en raison d’une obligation légale. Les messages de demande peuvent être conservés le temps nécessaire à leur traitement et au respect des obligations applicables ; il n’existe pas de durée supplémentaire fixe définie dans l’application.
